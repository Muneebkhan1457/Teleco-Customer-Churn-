# 📊 Telco Customer Churn Predictor

This is an end-to-end MLOps project that predicts customer churn using machine learning.

### 🚀 Features
- **Automated CI/CD:** GitHub Actions triggers retraining on every push.
- **Model Registry:** Best models are automatically tracked and registered via MLflow on DagsHub.
- **Data Versioning:** DVC manages data and model artifacts.
- **Interactive UI:** Built with Streamlit for easy predictions.

### 🛠️ Tech Stack
- **Python** (Scikit-learn, Pandas)
- **MLflow** (Experiment Tracking)
- **DVC** (Data Version Control)
- **Docker** (Containerization)
- **Streamlit** (Frontend)
- **GitHub Actions** (CI/CD)
